בבדיקה: 24 מתוך 26 שאלות אמיתיות נענו נכון, ו"מה השעה" / "מתכון לפסטה" נענו — נכון — בכלום.

היתרון האמיתי כאן הוא לא החינם: זה ש**הבוט לא יכול להמציא**. הוא מחזיר טקסט
שנכתב מהמדריכים ומהמחקר שבהם, ולא ניחוש של מודל.

## התקנה

### הדרך הקצרה — פקודה אחת

צריך חשבון Cloudflare חינמי ([הרשמה](https://dash.cloudflare.com/sign-up) — **בלי כרטיס אשראי**),
ואז התחברות חד-פעמית שדורשת דפדפן:

```bash
npx wrangler login
```

נפתח דפדפן, לוחצים **Allow**, וזה כל מה שדורש אותך. ואז:

```bash
BOT_TOKEN='הטוקן-מ-BotFather' ./setup.sh
```

הסקריפט עושה את כל השאר לבד: מתקין תלויות · מאמת את הטוקן מול טלגרם · יוצר את מאגר
ה-KV ומעדכן את `wrangler.toml` · מייצר `WEBHOOK_SECRET` רנדומלי · מגדיר את הסודות ·
פורס · רושם את ה-webhook ואת תפריט הפקודות · ומריץ בדיקת שפיות שמדפיסה באיזה יום
של התוכנית אתה נמצא. הוא אידמפוטנטי — אפשר להריץ שוב בבטחה.

בסוף פתח את [t.me/kobi_stop_smoking_bot](https://t.me/kobi_stop_smoking_bot) ושלח **`/start`**.
זה מה שמלמד את הבוט לאן לשלוח את הודעות הבוקר והערב — **בלי `/start` אין הודעות מתוזמנות.**
הבוט נועל את עצמו לצ׳אט הראשון שעשה `/start`; אף אחד אחר לא יכול להשתמש בו.

### בלי דפדפן

אם עדיף API Token: צור אחד עם הרשאת *Edit Cloudflare Workers* ב-[api-tokens](https://dash.cloudflare.com/profile/api-tokens), ואז

```bash
export CLOUDFLARE_API_TOKEN='...' && BOT_TOKEN='...' ./setup.sh
```

### ידנית, שלב-שלב

`npm install` → `npx wrangler kv namespace create BOT_KV` (ה-id ל-`wrangler.toml`) →
`npx wrangler secret put BOT_TOKEN` → `npx wrangler secret put WEBHOOK_SECRET` →
`npm run deploy` → למלא `.env` לפי `.env.example` → `npm run webhook:set`.

### אחרי ההתקנה

```bash
npx wrangler tail
```

לוגים בזמן אמת. ולבדיקת מצב מלאה:

```bash
curl "$(grep WORKER_URL .env | cut -d= -f2)/diag?key=$(cat .webhook-secret)"
```

## GitHub (אופציונלי)

הריפו הזה יכול להיות **public** — אין בו טוקנים.

```bash
git init
git add -A
git commit -m "בוט ליווי לגמילה מוויפ"
gh repo create kobi-stop-smoking-bot --public --source=. --push
```

שלושה workflows מוכנים ב-`.github/workflows/`:

| Workflow | מה הוא עושה | Secrets |
|---|---|---|
| `deploy.yml` | פריסה אוטומטית בכל push ל-main (עם בדיקת תקינות לפני) | `CLOUDFLARE_API_TOKEN` (הרשאת *Edit Cloudflare Workers*), `CLOUDFLARE_ACCOUNT_ID` |
| `watchdog.yml` | **קרון-גיבוי** כל חצי שעה — אם הקרון של Cloudflare נכשל או התעכב, ההודעות עדיין יוצאות. וגם בדיקת בריאות: אם ה-Worker מושתק, ה-job נכשל ו-GitHub שולח לך מייל | `WORKER_URL`, `WEBHOOK_SECRET` |
| `backup.yml` | גיבוי יומי של היומן, **מוצפן AES-256** לפני ההעלאה (90 יום) | `WORKER_URL`, `WEBHOOK_SECRET` |

> **הטוקן של הבוט לא נדרש באף workflow** — בכוונה. ההתראה על תקלה מגיעה
> ממערכת המיילים של GitHub, לא מהבוט.
>
> **ולגבי הגיבוי:** ב-repo ציבורי, Artifacts נגישים לכל מי שיש לו הרשאת קריאה —
> כלומר לכולם. לכן הגיבוי **מוצפן ב-AES-256** לפני ההעלאה, והסיסמה היא
> `WEBHOOK_SECRET` (יושב ב-Secrets, לא בקוד). לפענוח:
>
> ```bash
> openssl enc -d -aes-256-cbc -pbkdf2 -iter 600000 -in journal.json.enc -out journal.json -pass pass:"$(cat .webhook-secret)"
> ```
>
> `deploy.yml` מדלג בשקט על הפריסה כשאין `CLOUDFLARE_API_TOKEN`, כדי שלא תקבל
> מייל כישלון על כל commit. `CLOUDFLARE_ACCOUNT_ID` כבר מוגדר.

> ⚠️ **אל תשים את הטוקן של הבוט בריפו.** אם הוא נחשף אי-פעם — `/revoke` ב-BotFather,
> ואז `npx wrangler secret put BOT_TOKEN` עם הטוקן החדש + `npm run webhook:set` מחדש.

## מבנה

```
src/index.js      Worker: webhook (תגובות מיידיות) + cron (הודעות מתוזמנות)
src/plan.js       לוח 70 הימים, מדבקות, שעון ישראל

src/messages.js   בוני ההודעות והמקלדות
src/store.js      מצב ב-KV: meta (הגדרות + סכומים) · d:YYYY-MM-DD (יומן יומי)
src/kb.js         בסיס הידע מהמדריכים + אחזור בעברית (השכבה ה"מדברת", בלי AI)
src/ai.js         שכבת AI אופציונלית, מעוגנת ב-kb.js. כבויה כברירת מחדל
src/analytics.js  מיפוי דפוסים, גזירת אם-אז, וזיהוי נקודת ההסלמה (סעיף יב׳)
src/telegram.js   עטיפה דקה סביב Bot API, בלי תלויות
scripts/set-webhook.mjs   רישום/בדיקה/מחיקה של ה-webhook
setup.sh          התקנה מקצה לקצה בפקודה אחת
```

**נקודות קצה** (כולן מוגנות ב-`WEBHOOK_SECRET`, חוץ מ-`/health`):

**למה cron כל 10 דקות ולא 6 טריגרים?** כי Cloudflare מריץ cron ב-UTC בלבד.
הקוד קורא את שעון ישראל בעצמו (`Asia/Jerusalem`), אז שעון קיץ מטופל לבד, אין כפילויות,
וקרון שהתעכב עדיין שולח — עד "חלון חסד" שמוגדר לכל משבצת. 144 הרצות ביום מול מגבלה
של 100,000 בקשות ביום במסלול החינמי.
