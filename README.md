## לדבר איתו

**כן, זה שיח חופשי.** כותבים משפט בעברית — "היה לי יום קשה ואשתי בחוץ ואני מרגיש שאני מתפרק",
"בא לי לוותר אחרי 20 יום", "אשתי מציעה לי שאקח שאכטה אחת, מה אני אומר לה?" — ומקבלים
תשובה ממשית, מעוגנת במדריכים, עם ציון המקור.

**והמודל הוא זה שמבין את הכוונה, לא רשימת מילים.** בקריאה אחת הוא גם מסווג
מה אתה מתכוון וגם מנסח את התשובה, והבוט פועל לפי הסיווג: כוונת קנייה מפעילה את
זרימת הגל המודרכת, "קניתי" מריץ את נוהל 90 השניות, "לקחתי מסטיק" נרשם, וכן הלאה.
בכל ניסוח — גם כזה שאף אחד לא חשב עליו מראש.

<b>למה זה נבנה כך:</b> הגרסה הראשונה ניתבה טקסט חופשי לפי רשימת מילות מפתח,
וזו רשימת-היתר: כל ניסוח שלא נמצא בה נופל דרכה. זה קרה בפועל על המשפט הגרוע
ביותר שאפשר — <i>"אני רוצה ללכת לקנות וויפ"</i> נשמר ביומן במקום להפעיל את הזרימה.
התיקון לא היה רשימה ארוכה יותר, אלא להעביר את ההבנה למודל.

זה בנוי בשלוש שכבות, **וכולן חינמיות**:

| שכבה | מה זה | מה קורה כשנגמר |
|---|---|---|
| 1 · **Gemini** `gemini-flash-lite-latest` | הספק הראשי. עברית מצוינת, ~1 שנייה, בלי טוקני "חשיבה" | מכסה שנגמרה = HTTP 429, **לא חשבון** → יורד לשכבה 2 |
| 2 · **Cloudflare Workers AI** `gpt-oss-120b` | 10,000 נוירונים/יום, באותו Worker, בלי מפתח | → יורד לשכבה 3 |
| 3 · **בסיס הידע** (38 נושאים) | אחזור מהמדריכים. אף פעם לא נגמר, אף פעם לא עולה | — |

ומעל הכל: **מסלול מהיר** בביטוי רגולרי לניסוחים חד-משמעיים של דחף, כדי שברגע
אמת התשובה תהיה מיידית ולא תמתין לרשת. כלל האיחוד — אם המסלול המהיר *או*
המודל אומרים "דחף", מפעילים את הזרימה. לא חיתוך, איחוד.

**וההודעה תמיד מגיעה:** אם טלגרם דוחה HTML שהמודל הפיק, הבוט שולח שוב כטקסט
נקי. עדיף הודעה בלי עיצוב מאשר שתיקה ברגע דחף.

**מצוקה שחורגת מהוויפ** מזוהה בנפרד (`crisis`) ומקבלת תשובה אחרת לגמרי: בלי כלים
של גמילה, עם ער״ן <b>1201</b> וסה״ר, ועם אמירה מפורשת שהבוט אינו תחליף לאדם.

השרשרת מוגדרת ב-`AI_PROVIDER = "gemini,workers-ai"`. אם הראשון נופל מכל סיבה,
הבא בתור עונה. השיחה לא נשברת, ואי-אפשר להגיע לחיוב.

### למה Gemini ולא Workers AI — נמדד, לא נוחש

הרצתי את אותן ארבע שאלות אמיתיות דרך כל המודלים החינמיים:

שתי מלכודות שנפלתי בהן ותוקנו: מודלי Gemini 2.5 עם "חשיבה" שורפים את תקציב
הטוקנים על מחשבות והתשובה נחתכת באמצע מילה (`flash-lite` הוא היחיד עם 0 חשיבה);
ו-`thinkingConfig` נדחה ב-400 על הכינויים ב-`-latest`.

### האם זה באמת חינם לתמיד

כן, ובלי כוכביות: השכבה החינמית של Gemini היא **מוגבלת-קצב, לא מחויבת**. כשעוברים את
המכסה מקבלים 429 ועוצרים — אף פעם לא חשבון. חיוב אפשרי רק אם *מחברים* חשבון
תשלום לפרויקט, וזה לא נעשה כאן. לשימוש של אדם אחד המכסה היומית רחוקה מאוד ממה שתגיע אליו,
ובנוסף יש `AI_DAILY_CAP` (ברירת מחדל 40 תשובות ביום) שעוצר עוד לפני.

⚠️ **הערה על המפתח:** הוא יושב כ-secret של ה-Worker, לא בריפו. אבל הוא הודבק בצ׳אט,
ולכן כדאי להחליף אותו: מוחקים ומייצרים חדש ב-[aistudio.google.com/apikey](https://aistudio.google.com/apikey),
ואז `npx wrangler secret put GEMINI_KEY`.

`/ai` בצ׳אט מראה איזה ספק פעיל וכמה תשובות נשארו היום.

## התקנה

### הדרך הקצרה — פקודה אחת

צריך חשבון Cloudflare חינמי ([הרשמה](https://dash.cloudflare.com/sign-up) — **בלי כרטיס אשראי**),
ואז התחברות חד-פעמית שדורשת דפדפן:

```bash
npx wrangler login
```

נפתח דפדפן, לוחצים **Allow**, וזה כל מה שדורש אותך. ואז:

```bash
BOT_TOKEN='הטוקן-מ-BotFather' ./setup.sh
```

הסקריפט עושה את כל השאר לבד: מתקין תלויות · מאמת את הטוקן מול טלגרם · יוצר את מאגר
ה-KV ומעדכן את `wrangler.toml` · מייצר `WEBHOOK_SECRET` רנדומלי · מגדיר את הסודות ·
פורס · רושם את ה-webhook ואת תפריט הפקודות · ומריץ בדיקת שפיות שמדפיסה באיזה יום
של התוכנית אתה נמצא. הוא אידמפוטנטי — אפשר להריץ שוב בבטחה.

בסוף פתח את [t.me/kobi_stop_smoking_bot](https://t.me/kobi_stop_smoking_bot) ושלח **`/start`**.
זה מה שמלמד את הבוט לאן לשלוח את הודעות הבוקר והערב — **בלי `/start` אין הודעות מתוזמנות.**
הבוט נועל את עצמו לצ׳אט הראשון שעשה `/start`; אף אחד אחר לא יכול להשתמש בו.

### בלי דפדפן

אם עדיף API Token: צור אחד עם הרשאת *Edit Cloudflare Workers* ב-[api-tokens](https://dash.cloudflare.com/profile/api-tokens), ואז

```bash
export CLOUDFLARE_API_TOKEN='...' && BOT_TOKEN='...' ./setup.sh
```

### ידנית, שלב-שלב

`npm install` → `npx wrangler kv namespace create BOT_KV` (ה-id ל-`wrangler.toml`) →
`npx wrangler secret put BOT_TOKEN` → `npx wrangler secret put WEBHOOK_SECRET` →
`npm run deploy` → למלא `.env` לפי `.env.example` → `npm run webhook:set`.

### אחרי ההתקנה

```bash
npx wrangler tail
```

לוגים בזמן אמת. ולבדיקת מצב מלאה:

```bash
curl "$(grep WORKER_URL .env | cut -d= -f2)/diag?key=$(cat .webhook-secret)"
```

שלושה workflows מוכנים ב-`.github/workflows/`:

| Workflow | מה הוא עושה | Secrets |
|---|---|---|
| `deploy.yml` | פריסה אוטומטית בכל push ל-main (עם בדיקת תקינות לפני) | `CLOUDFLARE_API_TOKEN` (הרשאת *Edit Cloudflare Workers*), `CLOUDFLARE_ACCOUNT_ID` |
| `watchdog.yml` | **קרון-גיבוי** כל חצי שעה — אם הקרון של Cloudflare נכשל או התעכב, ההודעות עדיין יוצאות. וגם בדיקת בריאות: אם ה-Worker מושתק, ה-job נכשל ו-GitHub שולח לך מייל | `WORKER_URL`, `WEBHOOK_SECRET` |
| `backup.yml` | גיבוי יומי של היומן, **מוצפן AES-256** לפני ההעלאה (90 יום) | `WORKER_URL`, `WEBHOOK_SECRET` |

> **הטוקן של הבוט לא נדרש באף workflow** — בכוונה. ההתראה על תקלה מגיעה
> ממערכת המיילים של GitHub, לא מהבוט.
>
> **ולגבי הגיבוי:** ב-repo ציבורי, Artifacts נגישים לכל מי שיש לו הרשאת קריאה —
> כלומר לכולם. לכן הגיבוי **מוצפן ב-AES-256** לפני ההעלאה, והסיסמה היא
> `WEBHOOK_SECRET` (יושב ב-Secrets, לא בקוד). לפענוח:
>
> ```bash
> openssl enc -d -aes-256-cbc -pbkdf2 -iter 600000 -in journal.json.enc -out journal.json -pass pass:"$(cat .webhook-secret)"
> ```
>

## איך משנים דברים

| מה | איפה |
|---|---|
| תאריך ההפסקה, מינונים, מקומות הדבקה, מיקוד שבועי, טיפים יומיים, אבני דרך | `src/plan.js` |
| שעות ההודעות | `SLOTS` בראש `src/index.js` |
| התובנות, RAIN, האם-אז, מדריך המסטיק, כל הטקסטים | `src/content.js` |
| מבנה ההודעות והכפתורים | `src/messages.js` |
| מקסימום מסטיק להתראה, עלות יומית, משפט הזהות | `DEFAULT_META` ב-`src/store.js` (או `/כסף`, `/זהות` בצ׳אט) |
| תשובות לשאלות (בסיס הידע) | `src/kb.js` — כל רשומה: מילות מפתח, כותרת, תשובה, מקור |
| ספק ה-AI וההנחיות שלו | `src/ai.js` |
| תגיות ההקשר, חוקי ההסלמה, נוסח שורות האם-אז המוצעות | `src/analytics.js` |

אחרי כל שינוי: `npm run deploy`. לבדיקת תקינות לפני פריסה: `npm run check`.
לצפייה בלוגים בזמן אמת: `npm run tail`.

## מבנה

```
src/index.js      Worker: webhook (תגובות מיידיות) + cron (הודעות מתוזמנות)
src/plan.js       לוח 70 הימים, מדבקות, שעון ישראל
src/content.js    כל התוכן המנטלי — תובנות, RAIN, כלים, מדריכים
src/messages.js   בוני ההודעות והמקלדות
src/store.js      מצב ב-KV: meta (הגדרות + סכומים) · d:YYYY-MM-DD (יומן יומי)
src/kb.js         בסיס הידע מהמדריכים + אחזור בעברית (השכבה ה"מדברת", בלי AI)
src/ai.js         שכבת AI אופציונלית, מעוגנת ב-kb.js. כבויה כברירת מחדל
src/analytics.js  מיפוי דפוסים, גזירת אם-אז, וזיהוי נקודת ההסלמה (סעיף יב׳)
src/telegram.js   עטיפה דקה סביב Bot API, בלי תלויות
scripts/set-webhook.mjs   רישום/בדיקה/מחיקה של ה-webhook
setup.sh          התקנה מקצה לקצה בפקודה אחת
```

**נקודות קצה** (כולן מוגנות ב-`WEBHOOK_SECRET`, חוץ מ-`/health`):
`/` webhook · `/health` · `/diag` מצב מלא כ-JSON · `/cron` הרצת קרון ידנית ·
`/export` גיבוי היומן · `/send?slot=morning|evening|noon|risk|micro1|micro2` שליחה כפויה
(לא מסמנת כ"נשלח", כדי שבדיקה לא תבטל את ההודעה המתוזמנת האמיתית)

**למה cron כל 10 דקות ולא 6 טריגרים?** כי Cloudflare מריץ cron ב-UTC בלבד.
הקוד קורא את שעון ישראל בעצמו (`Asia/Jerusalem`), אז שעון קיץ מטופל לבד, אין כפילויות,
וקרון שהתעכב עדיין שולח — עד "חלון חסד" שמוגדר לכל משבצת. 144 הרצות ביום מול מגבלה
של 100,000 בקשות ביום במסלול החינמי.
